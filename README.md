# justadityaraj/tap

Homebrew formulae for my open-source Mac tools.

```bash
brew install justadityaraj/tap/switchboard
brew install justadityaraj/tap/foldout
```

| Formula | What it is |
| --- | --- |
| `switchboard` | [Switchboard Browser Picker](https://dev.adityarajsingh.com/switchboard/): open each link in the right browser, Chrome or Brave profile, or private window. Built from source on your Mac, so macOS shows no "unverified developer" warning. |
| `foldout` | [Foldout Folder Preview](https://dev.adityarajsingh.com/foldout/): press Space on a folder in Finder to see its real size, file types, largest and newest files, git status and README. Built from source on your Mac, so macOS shows no "unverified developer" warning. |
