# justadityaraj/tap

Homebrew formulae for my open-source Mac tools.

```bash
brew install justadityaraj/tap/switchboard
```

| Formula | What it is |
| --- | --- |
| `switchboard` | [Switchboard Browser Picker](https://dev.adityarajsingh.com/switchboard/): open each link in the right browser, Chrome or Brave profile, or private window. Built from source on your Mac, so macOS shows no "unverified developer" warning. |
